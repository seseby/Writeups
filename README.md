---

## 🧭 Estructura de los Writeups

Cada writeup sigue una metodología uniforme creada desde **Obsidian**:

- 📌 **Resumen Ejecutivo:** Visión general del reto y la secuencia de pasos.
- 🔍 **Reconocimiento y Enumeración:** Escaneo de puertos (Nmap), fuzzing web (Gobuster) y análisis de servicios.
- 🛡️ **Análisis de Vulnerabilidades:** Identificación de CVEs y fallos de configuración.
- 🚀 **Acceso Inicial:** Análisis web y obtención de consola/credenciales.
- ⚡ **Escalada de Privilegios:** Abuso de binarios, permisos `sudo`, SUID o archivos del sistema.
- 🎯 **Conclusiones y Defensas:** Lecciones aprendidas y recomendaciones de remediación.
